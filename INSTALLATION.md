# 🚀 Руководство по развертыванию проекта

## Oxbridge International School Website - Инструкция по установке

---

## 📋 Требования

Перед началом убедитесь что у вас установлено:

- **Node.js** версии 18.0.0 или выше
- **pnpm** (рекомендуется) или **npm**

---

## 🔧 Шаг 1: Проверка Node.js

Откройте терминал (командную строку) и выполните:

```bash
node --version
```

Должно показать версию 18.0.0 или выше (например: `v20.10.0`)

### Если Node.js не установлен:

**Windows:**
1. Скачайте установщик: https://nodejs.org/
2. Выберите LTS версию
3. Запустите установщик и следуйте инструкциям

**macOS:**
```bash
# Используя Homebrew
brew install node
```

**Linux (Ubuntu/Debian):**
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

---

## 📦 Шаг 2: Установка пакетного менеджера

### Вариант A: pnpm (Рекомендуется)

```bash
npm install -g pnpm
```

Проверка установки:
```bash
pnpm --version
```

### Вариант B: npm (Встроен в Node.js)

npm уже установлен вместе с Node.js, дополнительных действий не требуется.

---

## 📥 Шаг 3: Установка зависимостей проекта

Откройте терминал в корневой папке проекта и выполните:

### Если используете pnpm:
```bash
pnpm install
```

### Если используете npm:
```bash
npm install
```

Этот процесс может занять 2-5 минут в зависимости от скорости интернета.

**Что происходит:**
- Загружаются все необходимые библиотеки
- Создается папка `node_modules`
- Создается файл `pnpm-lock.yaml` или `package-lock.json`

---

## ▶️ Шаг 4: Запуск проекта (Development режим)

После установки зависимостей запустите dev-сервер:

### Если используете pnpm:
```bash
pnpm dev
```

### Если используете npm:
```bash
npm run dev
```

**Вы увидите сообщение:**
```
  VITE v5.x.x  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

---

## 🌐 Шаг 5: Открыть проект в браузере

Откройте браузер и перейдите по адресу:

```
http://localhost:5173/
```

🎉 **Готово!** Сайт должен открыться.

## 🔥 Hot Reload (Автообновление)

В режиме разработки (`pnpm dev`) изменения применяются автоматически:

- ✅ Измените файл `.tsx`
- ✅ Сохраните (Ctrl+S или Cmd+S)
- ✅ Страница обновится автоматически
- ⚡ Не нужно перезапускать сервер!

---

## ⚠️ Решение проблем

### Проблема: "command not found: pnpm"
**Решение:**
```bash
npm install -g pnpm
```

### Проблема: "Cannot find module..."
**Решение:**
```bash
# Удалите node_modules и переустановите
rm -rf node_modules
pnpm install
```

### Проблема: "Port 5173 is already in use"
**Решение 1:** Закройте другое приложение использующее порт 5173

**Решение 2:** Используйте другой порт:
```bash
pnpm dev --port 3000
```

### Проблема: "Permission denied"
**Решение (Linux/macOS):**
```bash
sudo chown -R $USER node_modules
```

### Проблема: Страница белая / не загружается
**Решение:**
1. Проверьте консоль браузера (F12)
2. Проверьте терминал на наличие ошибок
3. Попробуйте перезапустить dev-сервер (Ctrl+C, затем `pnpm dev`)

### Проблема: Изменения не применяются
**Решение:**
1. Сохраните файл (Ctrl+S)
2. Обновите страницу (Ctrl+R или Cmd+R)
3. Очистите кэш браузера (Ctrl+Shift+R)
4. Перезапустите dev-сервер

## 📱 Тестирование на мобильных устройствах

### Шаг 1: Узнайте свой IP адрес

**Windows:**
```bash
ipconfig
```
Ищите "IPv4 адрес" (например: `192.168.1.100`)

**macOS/Linux:**
```bash
ifconfig | grep inet
```

### Шаг 2: Запустите с доступом по сети
```bash
pnpm dev --host
```

### Шаг 3: Откройте на мобильном
На вашем телефоне (в той же WiFi сети) откройте:
```
http://ваш-ip:5173
```
Например: `http://192.168.1.100:5173`

## 🔐 Переменные окружения (если используются)

Если проект использует API ключи или другие секреты:

1. Создайте файл `.env` в корне проекта:

VITE_API_KEY=your_api_key_here

2. Используйте в коде:
```typescript
const apiKey = import.meta.env.VITE_API_KEY;
```

**⚠️ Важно:** Не коммитьте файл `.env` в Git!
