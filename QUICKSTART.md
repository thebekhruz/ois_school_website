# ⚡ БЫСТРАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ

## 🚀 3 шага до запуска проекта

### 1️⃣ Установите Node.js (если нет)
Скачайте с: https://nodejs.org/ (выберите LTS версию)

Проверьте установку:
```bash
node --version
```
Должно показать v18 или выше.

---

### 2️⃣ Установите зависимости
Откройте терминал в папке проекта и выполните:

```bash
pnpm install
```

**Если pnpm не установлен:**
```bash
npm install -g pnpm
# затем
pnpm install
```

**Или используйте npm:**
```bash
npm install
```

Подождите 2-5 минут пока установятся все пакеты.

---

### 3️⃣ Запустите проект
```bash
pnpm dev
```

или

```bash
npm run dev
```

Откройте браузер: **http://localhost:5173**

---

## ✅ Готово!

Сайт должен открыться. Изменения в коде применяются автоматически.

---

## 🛑 Остановить сервер

Нажмите `Ctrl+C` в терминале

## ❓ Проблемы?

### "command not found: pnpm"
```bash
npm install -g pnpm
```

### "Port 5173 is already in use"
```bash
pnpm dev --port 3000
```

### Страница не загружается
1. Проверьте что сервер запущен
2. Обновите страницу (Ctrl+R)
3. Проверьте адрес: http://localhost:5173

### Изменения не применяются
1. Сохраните файл (Ctrl+S)
2. Проверьте терминал на ошибки
3. Перезапустите сервер (Ctrl+C → pnpm dev)
