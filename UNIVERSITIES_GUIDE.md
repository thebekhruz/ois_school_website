## 🎯 Быстрый старт

### 1. Как добавить новый университет

**Шаг 1:** Откройте файл `/src/data/universities.ts`

**Шаг 2:** Скопируйте шаблон в конце файла:

```typescript
{
  id: 999,                                    // Уникальный номер
  name: 'Название Университета',              // Полное название
  location: 'Город, Область',                 // Местоположение
  country: 'CountryName',                     // Страна (для фильтров)
  coordinates: [долгота, широта],             // [longitude, latitude]
  students: 5,                                // Количество студентов
  year: '2024',                               // Год поступления
  program: 'IB Diploma',                      // или 'Russian Program'
  ranking: 50,                                // (необязательно) Рейтинг QS
  logo: '/university-logos/filename.png'      // (необязательно) Путь к логотипу
},
```

**Шаг 3:** Заполните данные

**Шаг 4:** Добавьте в конец массива `universities`

**Шаг 5:** Сохраните файл

**Шаг 4:** Сохраните файл

## 🗺️ Как найти координаты университета

### Метод 1: Google Maps (Рекомендуется)

1. Откройте [Google Maps](https://www.google.com/maps)
2. Найдите университет в поиске
3. Кликните правой кнопкой мыши на маркер университета
4. Выберите первую строку с координатами (они автоматически скопируются)
5. Вы получите координаты в формате: `42.3770, -71.1167`
6. **ВАЖНО:** В файле порядок обратный: `[-71.1167, 42.3770]`

**Пример:**
- Google Maps показывает: `42.3770, -71.1167` (широта, долгота)
- В файл вставляем: `[-71.1167, 42.3770]` (долгота, широта)

### Метод 2: latlong.net

1. Откройте [latlong.net](https://www.latlong.net/)
2. Введите адрес университета
3. Скопируйте координаты
4. Вставьте в формате `[долгота, широта]`

## 🖼️ Как добавить логотип университета

### Шаг 1: Подготовка логотипа

**Рекомендации:**
- ✅ Формат: PNG с прозрачным фоном (лучший вариант)
- ✅ Альтернатива: JPG или PNG с белым фоном
- ✅ Размер: минимум 200x200px, рекомендуется 400x400px
- ✅ Качество: Официальный логотип из брендбука университета
- ✅ Имя файла: используйте английские буквы, цифры и дефисы
  - ✅ Правильно: `harvard.png`, `mit-logo.png`, `oxford-uni.png`
  - ❌ Неправильно: `Гарвард.png`, `MIT Logo.png`, `oxford uni.png`

### Шаг 2: Сохранение логотипа

1. Создайте папку `/public/university-logos/` (если её нет)
2. Сохраните файл логотипа в эту папку
3. Запомните имя файла (например: `harvard.png`)

### Шаг 3: Добавление пути в данные

1. Откройте `/src/data/universities.ts`
2. Найдите университет
3. Добавьте или измените поле `logo`:
   ```typescript
   logo: '/university-logos/harvard.png'
   ```

### Примеры:

```typescript
// С логотипом
{
  id: 1,
  name: 'Harvard University',
  // ... другие поля ...
  logo: '/university-logos/harvard.png'  // ← Путь к логотипу
},

// Без логотипа (поле logo можно не указывать)
{
  id: 4,
  name: 'Yale University',
  // ... другие поля ...
  // logo не указан - университет будет отображаться на карте, но не в сетке логотипов
},
```

## 📋 Описание полей

### Обязательные поля:

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `id` | number | Уникальный идентификатор | `31` |
| `name` | string | Название университета | `'Harvard University'` |
| `location` | string | Город и регион | `'Cambridge, MA'` |
| `country` | string | Страна (для фильтров) | `'USA'`, `'UK'`, `'Russia'` |
| `coordinates` | [number, number] | Координаты [долгота, широта] | `[-71.1167, 42.3770]` |
| `students` | number | Количество наших студентов | `12` |
| `year` | string | Год поступления | `'2023'`, `'2024'` |
| `program` | string | Программа обучения | `'IB Diploma'` или `'Russian Program'` |

### Необязательные поля:

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `ranking` | number | Позиция в рейтинге QS | `1`, `25`, `100` |
| `logo` | string | Путь к логотипу | `'/university-logos/harvard.png'` |

## ⚠️ Важные моменты

### 1. ID должны быть уникальными

❌ **Неправильно:**
```typescript
{ id: 10, name: 'University A', ... },
{ id: 10, name: 'University B', ... },  // Дубликат ID!
```

✅ **Правильно:**
```typescript
{ id: 10, name: 'University A', ... },
{ id: 11, name: 'University B', ... },  // Уникальный ID
```

### 2. Порядок координат

В Google Maps координаты показываются как: **широта, долгота**
В файле нужно указывать: **долгота, широта**

❌ **Неправильно:**
```typescript
coordinates: [42.3770, -71.1167]  // Порядок из Google Maps
```

✅ **Правильно:**
```typescript
coordinates: [-71.1167, 42.3770]  // Перевернутый порядок
```

### 3. Страна для фильтров

Используйте английские названия стран для корректной работы фильтров:
- ✅ `'USA'`, `'UK'`, `'Canada'`, `'Russia'`, `'Germany'`
- ❌ `'США'`, `'Великобритания'`, `'РФ'`

### 4. Формат года

Год должен быть строкой (в кавычках):
- ✅ `year: '2024'`
- ❌ `year: 2024`

### 5. Программа обучения

Используйте только эти два варианта:
- `'IB Diploma'` - для международных программ
- `'Russian Program'` - для российских программ

## 🎨 Где искать официальные логотипы

### Рекомендуемые источники:

1. **Официальный сайт университета** (раздел "Press" или "Brand Guidelines")
   - Пример: `harvard.edu/brand-guidelines`

2. **Brands of the World** - [brandsoftheworld.com](https://www.brandsoftheworld.com/)

4. **Wikipedia** (раздел университета)
   - Обычно есть логотип в правой части страницы

### Как скачать логотип из Википедии:

1. Найдите страницу университета на Wikipedia
2. Кликните на логотип в правой колонке
3. Нажмите "More details"
4. Нажмите "Original file" или выберите нужное разрешение
5. Скачайте изображение

## ❓ FAQ (Часто задаваемые вопросы)

**Q: Что делать если координаты неправильные?**
A: Проверьте порядок: сначала долгота (longitude), потом широта (latitude). Если университет отображается не там, попробуйте поменять числа местами.

**Q: Логотип не отображается, что делать?**
A: Проверьте:
1. Файл находится в папке `/public/university-logos/`
2. Путь указан правильно (начинается с `/university-logos/`)
3. Имя файла написано точно так же (учитывая регистр)

**Q: Можно ли использовать русские названия в поле country?**
A: Нет, используйте английские названия для корректной работы фильтров.

**Q: Как узнать рейтинг QS университета?**
A: Посетите [topuniversities.com](https://www.topuniversities.com/university-rankings/world-university-rankings) или найдите "QS ranking [название университета]" в Google.

**Q: Сколько университетов можно добавить?**
A: Теоретически неограниченное количество, но для удобства восприятия рекомендуется до 50-100.

**Q: Нужно ли перезапускать сервер после изменений?**
A: Обычно нет - изменения применяются автоматически. Если изменения не видны, попробуйте обновить страницу в браузере (Ctrl+R или Cmd+R).
